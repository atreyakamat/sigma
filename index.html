Everything in one place

A full design tool, minus the rental agreement.

Built on a custom canvas engine, not a wrapper. Real vector tools, real components, real collaboration.

⚡

Realtime co-editing

Everyone in a file edits the same document. Live cursors, selections, comments pinned to layers, and a version history you can diff and roll back. Powered by a CRDT, with offline edits merged on reconnect.

Shipped
🧩

Design systems

Components, variants, overrides, auto layout, constraints and shared libraries.

✒️

Vector tools

Pen, pencil, path editing, booleans, SVG import and gradients you can edit.

🎬

Prototyping

Click, hover and keyboard triggers, transitions and overlays in a preview player.

🔗

Share links

Read-only links open without an account. Expire them or revoke in one click.

🛠️

Developer handoff

PNG, SVG and PDF export, design tokens as JSON or CSS, API tokens and a command-line tool.

🛡️

Yours to keep

Roles, two-factor sign-in, audit log, backups and restore. No telemetry. Your files never leave your machine unless you share them.

AI-ready

Ask for a change. Watch it happen.

An assistant inside the editor edits the file through validated operations, so everyone sees the result live and you can roll it back from version history.

  • Bring your own model: Claude, OpenAI, or a local one such as Ollama.
  • An MCP server and a ready-made skill let Claude Code build screens in SIGMA directly.
  • Viewers get a read-only assistant. Keys are stored encrypted.

🐳 One-line Docker

For a team server. Needs Docker Desktop. Creates secure settings and shows your sign-in.

curl -fsSL https://raw.githubusercontent.com/atreyakamat/sigma/main/install/install.sh | sh
irm https://raw.githubusercontent.com/atreyakamat/sigma/main/install/install.ps1 | iex

🧑‍💻 From source

Hack on it. TypeScript monorepo, MIT licensed.

git clone https://github.com/atreyakamat/sigma cd sigma && cp .env.docker.example .env.docker docker compose --env-file .env.docker up -d --build

Then open http://localhost:3387
